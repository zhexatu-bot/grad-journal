# 研究生工作记录

> 专为研究生设计的本地工作记录工具，帮你在组会、汇报、答辩时不再"脑子一片空白"。

## 为什么做这个？

读研之后你会发现一件事——**记忆是不可靠的**。

上周做了什么实验？调了什么参数？导师上次说了什么？踩过什么坑？

翻聊天记录？翻备忘录？翻了半小时找不到。

这个工具就是为了解决这个问题：**每天花两分钟记一下，需要的时候秒搜到。**

## 软件优势

### 1. 专为研究生场景设计

不是通用笔记软件，而是**专门为读研设计**的分类体系：

| 分类 | 记录什么 |
|------|---------|
| 📄 论文 | 文献阅读、写作进度、投稿状态 |
| 🧪 实验 | 实验设计、参数记录、结果分析 |
| 💻 代码 | 踩坑记录、环境配置、代码重构 |
| 👥 组会 | 导师反馈、讨论要点、待办事项 |
| 📋 项目 | 基金报告、项目进展、材料整理 |
| 📝 其他 | 日常记录、学习笔记、杂事 |

### 2. 全文搜索，秒速定位

标题和内容都能搜，不记得具体措辞也没关系，输个关键词就能找到。

> "上周那个 PyTorch 环境怎么配的来着" → 搜"PyTorch" → 秒出

### 3. 自定义标签，灵活归类

每条记录可以打多个标签，比如：
- `#踩坑` `#PyTorch` `#环境配置`
- `#导师` `#deadline` `#返工`

标签之间用逗号分隔，支持按标签筛选。

### 4. 统计面板，一目了然

- 本月记录了多少条
- 各分类的分布比例
- 按月的时间线图表
- 标签词云

**说得直白点——能看到自己到底有没有在干活。**

### 5. Markdown 支持

内容区支持 Markdown 语法：
- 标题、粗体、斜体
- 代码块（高亮显示）
- 列表、引用
- 表格

写技术记录、贴代码片段都很方便。

### 6. 数据导出

- **JSON 导出**：完整备份，随时恢复
- **Markdown 导出**：按时间线整理成可读文档，方便生成周报、月报

### 7. 100% 本地运行

| 特性 | 说明 |
|------|------|
| 不联网 | 所有数据存在本地，不需要联网 |
| 不注册 | 打开就用，没有账号系统 |
| 不上传 | 你的数据只在你的电脑上 |
| 隐私安全 | 离线运行，没有数据泄露风险 |

### 8. 零依赖，装完即用

- 不需要安装 Python、Node.js 或任何运行时
- Windows 双击安装包即可使用
- 安装包体积小，不占空间

### 9. 本地数据库，秒开秒关

使用 SQLite（sql.js WASM 版本），无需安装数据库服务：
- 启动即用，关闭即存
- 数据文件可直接备份拷贝
- 不依赖任何外部服务

## 使用场景

### 场景一：组会前

> 组会 10 分钟后开始，导师可能会问上周做了什么。
>
> 打开工作记录 → 搜"上周"或按日期筛选 → 30秒回顾完毕 → 心里有底了。

### 场景二：写周报/月报

> 每周要交周报，但想不起来这周具体干了啥。
>
> 打开工作记录 → 按本周日期筛选 → 导出 Markdown → 稍微整理就是周报。

### 场景三：踩坑复现

> 三个月前配过一个环境，当时踩了个坑解决了，现在又遇到同样的问题。
>
> 搜关键词"环境配置"或标签"#踩坑" → 找到当时的记录 → 按步骤解决。

### 场景四：论文写作

> 写论文的实验部分，需要回忆当时某个实验的参数和结果。
>
> 搜"实验参数" → 找到当时的记录 → 数据直接引用。

## 安装

### 方式一：下载安装包（推荐）

从 [Releases](../../releases) 下载最新版安装包，双击安装即可。

### 方式二：源码运行

```bash
# 克隆仓库
git clone https://github.com/zhexatu-bot/grad-journal.git
cd grad-journal

# 安装依赖
npm install

# 启动
npm start
```

## 技术栈

| 模块 | 技术 | 说明 |
|------|------|------|
| 桌面框架 | Electron | 跨平台桌面应用 |
| 后端 | Express | 本地 HTTP API |
| 数据库 | sql.js (SQLite WASM) | 无需安装数据库服务 |
| 前端 | HTML + CSS + 原生 JS | 轻量无框架 |
| 打包 | electron-builder | NSIS 安装包 |

## 项目结构

```
grad-journal/
├── main.js          # Electron 主进程
├── server.js        # Express API 服务
├── db.js            # SQLite 数据库操作
├── package.json
└── renderer/
    ├── index.html   # 页面结构
    ├── style.css    # 样式
    └── app.js       # 前端逻辑
```

## 数据存储

- **开发模式**：数据存储在项目目录下的 `data.db`
- **安装模式**：数据存储在 `%APPDATA%/grad-journal/data.db`

备份数据只需拷贝 `data.db` 文件即可。

## API

```
GET    /api/records              # 记录列表 (?search=&category=&tag=)
GET    /api/records/:id          # 单条记录详情
POST   /api/records              # 新建记录
PUT    /api/records/:id          # 更新记录
DELETE /api/records/:id          # 删除记录
GET    /api/stats                # 统计数据
GET    /api/categories           # 分类列表
GET    /api/export/json          # 导出 JSON
GET    /api/export/markdown      # 导出 Markdown
```
